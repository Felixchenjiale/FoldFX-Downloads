FoldFX
使用说明 GitHub

让开合盖，变成一种视觉体验。

随 MacBook 机盖角度，让桌面呈现投影与渐变毛玻璃效果。

下载 DMG 版

0.1.0（4） · Apple Silicon · macOS 15+

查看版本与校验

开始使用

  1. 01下载并打开 DMG
  2. 02拖入“应用程序”后打开
  3. 03授权屏幕录制，选择内置屏
  4. 04选择“自动跟随机盖”，开始效果

下载前请注意

适用于 Apple Silicon Mac，要求 macOS 15 及以上。自动机盖输入取决于硬件支持。

Direct 官网版，与沙盒版独立。当前未上架 App Store。

屏幕画面仅在本机内存处理，不保存、不上传。故障报告由你主动导出。
