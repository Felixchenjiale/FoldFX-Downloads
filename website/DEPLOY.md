# FoldFX 下载页部署说明

## 放到 chenxiaoyue.com 子页面

1. 解压 `FoldFX-Web-Page-0.1.0-4.zip`，获得 `foldfx` 目录和本说明。
2. 用现有网站的文件管理器、SFTP 或部署流程，将整个 `foldfx` 目录放到 chenxiaoyue.com 的网站根目录。不要覆盖网站原来的 `index.html`、服务器配置或其他文件。若目标目录已有内容，先备份并确认后再替换。
3. 访问 `https://chenxiaoyue.com/foldfx/`。此地址是默认部署目标，不表示已由发布者部署完成。
4. 点“下载 Direct 版”，确认可以从 GitHub 下载 `FoldFX-Direct-0.1.0-4-notarized.zip`；展开“版本与文件校验”，确认复制和下载校验文件正常。
5. 手机上打开同一地址，确认无横向滚动，图片、按钮和安装步骤可见。

可改用其他子目录，页面内部资源均为相对路径。保持整个目录结构，并以末尾带 `/` 的目录地址访问；服务器应将不带 `/` 的目录路径重定向到带 `/` 的路径。不要将页面资源拆散，也不要把所有 `.html` 都重写到网站主页面。

## 目录结构

```
foldfx/
  index.html

  app.js
  release.json
  assets/
```

这是纯静态页面，不需要安装 Node、不需要运行构建命令，也不需要新数据库、账号、统计服务或后端。安装包托管在 GitHub Releases，不必上传到你的网站服务器。

## 核对与后续更新

- 页面使用精确版本下载链接，不使用会自动变化的 `latest` 链接。以后升级版本时，需要同步修改页面中的版本、文件名、下载地址和 SHA-256，并再次验证。
- 配图是生成的效果意象，不是实机截图。不要删掉兼容性、隐私和实机验证范围说明。
- 页面不嵌入外部字体、第三方 JavaScript 或追踪统计。GitHub 下载和反馈仅在用户主动点击时打开。
- 网页包的哈希见同次发布中的 `WEB-SHA256SUMS`；应用安装包的哈希见 `SHA256SUMS`，二者不是同一文件。
- 发布者没有访问或修改 chenxiaoyue.com 服务器、主页、DNS 或 SSL 配置。上传后请由站点负责人确认真实 HTTPS 路径和响应；如果站点 CSP 禁止本站脚本或样式，请由站点负责人调整对应子页面规则，不要移除站点整体安全策略。
